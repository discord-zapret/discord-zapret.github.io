Антивирусы — не паникуйте

Драйвер WinDivert может вызвать ложное срабатывание (Not-a-virus:RiskTool.Multi.WinDivert). Это нормально — добавьте папку в исключения или отключите PUA. Все бинарники взяты из официального репозитория zapret, проверяйте по хэшам.

Остерегайтесь фейков

Автор не ведёт Telegram-каналы, YouTube или другие страницы. Всё, что распространяется вне официального GitHub репозитория — фейк и может содержать вредоносное ПО.

Как установить и запустить

Следуйте шагам ниже — весь процесс занимает около 5 минут

1

Включите Secure DNS в браузере

Chrome: Настройки → «Использовать безопасный DNS», выберите любого провайдера кроме дефолтного.
Firefox: Настройки → «DNS через HTTPS» → Максимальная защита → вставьте https://dns.google/dns-query.
Windows 11 поддерживает Secure DNS прямо в настройках ОС.

2

Скачайте архив

Загрузите ZIP или RAR архив со страницы релизов выше. Размер около 5 МБ.

3

Разблокируйте архив (опционально)

Щёлкните правой кнопкой по архиву → Свойства → поставьте галочку «Разблокировать». Этот шаг не нужен, если вы используете 7-Zip или PeaZip.

4

Распакуйте в надёжное место

Путь к папке не должен содержать кириллицу (русские буквы) и специальные символы. Например: C:\tools\discord-fix.

5

Запустите нужный файл

Перейдите в папку и запустите general.bat для ручного тестирования стратегий или service.bat для постоянного автозапуска.

Описание файлов

Инструмент предоставляет несколько вариантов работы в зависимости от ваших нужд

general.bat
Ручной запуск утилиты

Используется для ручного запуска и тестирования. После запуска откроется процесс winws.exe в панели задач. Пробуйте разные стратегии — ALT, FAKE и другие — пока не найдёте рабочее именно для вашего провайдера.

service.bat
Автозапуск и управление
  • Install / Remove Service — установка/удаление службы автозапуска в services.msc
  • Check Status — проверка состояния обхода и служб
  • Game Filter — режим фильтрации для игр (UDP/TCP >1023)
  • IPSet Filter — управление обходом по IP-спискам (none / loaded / any)
  • Update Hosts File — починка веб-версии Telegram и голосовых чатов Discord
  • Auto-Update Check — вкл/выкл автоматическую проверку обновлений
  • Update IPSet List — обновление списка ipset-all.txt
  • Run Diagnostics — диагностика + очистка кэша Discord
  • Run Tests — проверка стратегий и DPI чекеры

Частые вопросы

После запуска general* ничего не происходит
После запуска стратегии должен появиться процесс winws.exe в панели задач (иконка замочка). Если этого не произошло, откройте Диспетчер задач и проверьте наличие процесса. Если его нет — запустите service.bat → Run Diagnostics.
Не работает веб-Telegram или вечное «подключение» в Discord Voice
Запустите service.bat и выберите Update Hosts File. Если файл hosts устарел, скопируйте предложенное содержимое и вставьте в конец файла C:\Windows\System32\drivers\etc\hosts, открытого от имени администратора. Сохраните и перезагрузите браузер.
Обход не работает или перестал работать
Стратегии обхода со временем могут устаревать — это нормально. Попробуйте другие стратегии в general.bat (особенно ALT и FAKE). Запустите service.bat → Run Diagnostics для поиска типовых проблем. Если ни одна стратегия не помогает — потребуется создать новую на основе документации zapret.
Как правильно переустановить утилиту?
1. service.bat → Remove Services
2. service.bat → Run Diagnostics → в конце нажмите Y для очистки
3. Перезагрузите компьютер
4. Удалите папку с утилитой
5. Скачайте последнюю версию со страницы релизов
6. Распакуйте в папку без кириллицы и пробелов
7. Проверьте стратегии через general.bat
8. Установите рабочую стратегию: service.bat → Install Service
Не работает игра или приложение с запущенным запретом
В service.bat убедитесь, что Game Filter установлен в disabled, а IPSet Filter — в none. Эти режимы могут неожиданно затронуть трафик игр и других UDP-сервисов. После изменений перезапустите стратегию.
Античит ругается на WinDivert
Используйте скрытую версию драйвера WinDivert. Инструкция и файлы находятся в официальном репозитории: windivert-hide.
Windows 7 требует цифровую подпись драйвера
Замените файлы WinDivert.dll и WinDivert64.sys в папке bin на одноимённые файлы из папки zapret-win-bundle/win7 официального репозитория.
