Что такое zapret discord

zapret discord — это не отдельная программа, а популярное название для сборки утилиты zapret, настроенной специально для восстановления работы Discord и YouTube в России.

В 2024–2025 годах российские провайдеры начали массово ограничивать скорость или полностью блокировать Discord с помощью технологии DPI (Deep Packet Inspection) — глубокой инспекции трафика. Обычный DNS или смена провайдера не помогают: провайдер видит именно Discord-трафик и замедляет его.

zapret discord решает эту проблему, изменяя способ формирования TCP/UDP-пакетов так, чтобы DPI-система провайдера не могла их правильно классифицировать и применить блокировку.

Проект с открытым исходным кодом. zapret создан разработчиком bol-van и распространяется бесплатно. Discord Fix — это готовая сборка с удобными bat-скриптами и настройками именно для Discord и YouTube.

Как zapret discord обходит блокировки

Технически zapret discord использует несколько методов для обхода DPI:

  • Разбивка пакетов (packet fragmentation) — TCP-сегменты разбиваются на мелкие части, которые DPI не успевает собрать и проанализировать.
  • Fake-пакеты (FAKE стратегия) — перед настоящим TLS ClientHello отправляется поддельный пакет, сбивающий DPI с толку.
  • Модификация TTL — пакеты отправляются с низким значением TTL, до DPI они не «доживают», но до сервера Discord доходят.
  • WinDivert — драйвер для перехвата и модификации трафика на уровне ядра Windows, необходимый для работы zapret.

Именно поэтому антивирусы иногда помечают WinDivert как подозрительный инструмент — он перехватывает трафик. Но сам по себе WinDivert безопасен и используется в легальных приложениях.

Пошаговая установка zapret discord

Следуйте этому руководству для установки zapret discord на Windows 10 или Windows 11:

1

Включите Secure DNS

Chrome: Настройки → «Безопасность» → «Использовать безопасный DNS» → выберите Google или Cloudflare.
Firefox: Настройки → «Приватность» → «DNS через HTTPS» → Максимальная защита → вставьте https://dns.google/dns-query.
Windows 11: Параметры → Сеть → Свойства адаптера → DNS-сервер → включите DNS over HTTPS.

2

Скачайте архив zapret discord

Загрузите ZIP (рекомендуется) или RAR со страницы релизов. Текущая версия: 1.9.8c.

3

Разблокируйте архив в Windows

Правой кнопкой мыши на архиве → Свойства → галочка «Разблокировать» → ОК. Если используете 7-Zip или PeaZip — этот шаг пропустите.

4

Распакуйте в папку без кириллицы

Путь должен состоять только из латинских букв, цифр и дефисов. Пример: C:\tools\zapret. Путь C:\Папка\запрет — не подходит.

5

Запустите general.bat и выберите стратегию

Дважды щёлкните general.bat. Появится окно с выбором стратегии. Начните с первой (по умолчанию) — если Discord не заработал, пробуйте ALT, FAKE и другие варианты.

6

Установите в автозапуск (опционально)

Когда найдёте рабочую стратегию, запустите service.bat → Install Service. Теперь zapret discord будет запускаться автоматически вместе с Windows.

Стратегии обхода: какую выбрать

Разные провайдеры используют разные DPI-системы, поэтому zapret discord предлагает несколько стратегий обхода. Вот что означает каждая:

Основные стратегии

  • Стандартная (по умолчанию) — подходит для большинства провайдеров. Начинайте с неё.
  • ALT — альтернативный метод разбивки пакетов. Попробуйте, если стандартная не помогла.
  • FAKE — отправка fake-пакетов. Эффективна против некоторых типов DPI.
  • TPWS — обход на уровне TCP. Более агрессивный метод для сложных случаев.
Совет: Проверяйте работу Discord сразу после запуска каждой стратегии. Если через 30 секунд Discord не подключается — закройте winws.exe в панели задач и попробуйте следующую стратегию.

Когда стратегии перестают работать

Провайдеры периодически обновляют свои DPI-системы, и стратегия, работавшая месяц назад, может перестать работать. В таком случае:

  • Следите за обновлениями в репозитории Discord Fix
  • Запустите service.bat → Check for Updates
  • Используйте Run Tests для автоматической проверки всех стратегий

Решение проблем zapret discord

Discord не подключается после запуска zapret

Попробуйте другую стратегию. Убедитесь, что в панели задач есть иконка winws.exe (замочек). Запустите service.bat → Run Diagnostics.

Антивирус удаляет файлы zapret discord

WinDivert — легальный драйвер, антивирус реагирует ошибочно. Добавьте папку с zapret в исключения антивируса. В Windows Defender: Безопасность Windows → Защита от вирусов → Исключения → Добавить папку.

Голосовой чат Discord не работает (бесконечное подключение)

Запустите service.bat → Update Hosts File. Скопируйте содержимое из открывшегося блокнота и вставьте в конец файла C:\Windows\System32\drivers\etc\hosts, открытого от имени администратора.

Игры лагают или не подключаются с включённым zapret

В service.bat установите Game Filter = disabled и IPSet Filter = none. Перезапустите стратегию.

zapret discord не запускается на Windows 7

Замените файлы WinDivert.dll и WinDivert64.sys в папке bin на файлы из папки win7 официального репозитория zapret-win-bundle.

Частые вопросы о zapret discord

Что такое zapret discord и зачем он нужен?
zapret discord — это утилита для обхода DPI-блокировок, которую используют российские провайдеры для замедления Discord. Инструмент работает без VPN: он изменяет структуру пакетов так, чтобы DPI-система не могла их идентифицировать как Discord-трафик. В результате Discord работает с нормальной скоростью.
Безопасно ли использовать zapret discord?
Да. zapret — open-source проект с открытым кодом, который можно проверить самостоятельно. Бинарные файлы в Discord Fix взяты напрямую из официального репозитория bol-van/zapret и проверяются по хэшам. Антивирус может реагировать на WinDivert — это ложное срабатывание, добавьте папку в исключения.
zapret discord работает без VPN?
Да, именно так. zapret discord не нужен VPN. Он работает на уровне TCP/UDP-пакетов локально на вашем компьютере. Ваш трафик не проходит через сторонние серверы, скорость и пинг не ухудшаются.
На каких версиях Windows работает zapret discord?
zapret discord поддерживает Windows 7, Windows 10 и Windows 11. Для Windows 7 требуется заменить файлы WinDivert на версию для win7 из официального репозитория.
Почему zapret discord перестал работать?
Провайдеры периодически обновляют DPI-оборудование, и стратегии могут устаревать. Попробуйте другие стратегии в general.bat (ALT, FAKE и другие). Также обновите zapret discord до последней версии через страницу релизов — в обновлениях часто добавляются новые стратегии.
